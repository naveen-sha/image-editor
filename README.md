# Image Editor

A browser-based image editor built using HTML, CSS, and JavaScript.

## Features

* Upload images
* Apply filters

  * Brightness
  * Contrast
  * Blur
  * Saturation
  * Hue Rotation
* Reset filters to default values
* Real-time image preview

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository
2. Open `index.html` in your browser

Currently under development.
